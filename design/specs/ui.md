## 当前真相

首次启动且还没有工作区时，应用壳上弹出启动引导：介绍、能力、安装本机引擎、外观、打开文件夹、完成。窗口固定大约 800×540，中间一行单独滚动，底栏不盖住内容：淡描边卡片、能力页左名单右说明（标题不重复名单）、引擎三列、虚线文件夹区撑满剩余高度。底栏是进度点、跳过和胶囊按钮。工作区主按钮是继续，打开文件夹在虚线区；路径占位 Windows 用盘符、其它系统用 `~/`。关掉或走完写入 `preferences.setupGuideCompletedAt`，再打开时清空这次选过的文件夹名。已经有工作区的安装只补记这个时间，不再弹出。设置 → 通用可以再打开。不出现 git worktree 或另一套主题包编辑器。引擎是否就绪看探测 `status`（`ready` / `missing`），不是目录里的 `available`。安装按钮走现有 `agentTools.install`。上下文占用只在状态栏：百分比打开分桶卡，旁边是「压缩」。Composer 底栏不再画第二枚环。新一轮 `run.start` 仍清掉上一轮用量，避免旧数字被标成本轮实测。上下文窗口按当前引擎正在用的模型；交接未确认时看目标引擎，不用上一引擎的档案模型。顺序是 ACP `usage_update.size`、档案目录、厂商公开窗口（Claude 家族 200k，grok-4.6 为 2M，DeepSeek 官方 `deepseek-flash` / V4 为 1M）。都没有才写「{模型} · 未公布窗口」。会话里的模型覆盖只在当前引擎名单里生效。底栏芯片不常驻「已切换」。成功换模的微条「已切换到 {model}」独占改动条上方一行，不盖改动条和底栏芯片，数秒后消失。没有引擎默认模型时不算已切换。线程右缘刻度只含有正文的用户句，少于两句不出现。`submit_plan` 的「按此执行」只在该助手轮的计划卡片上，Composer 不再画第二条。审查文件树和 `@` 文件行按扩展名上色标，未知类型仍用代码文件图标。审查「更多」可把差异配色切到易辨认（新增走 accent，删除走 status-yellow，`+` / `-` 列保留），记在 `localStorage` 键 `enjoy-agents-diff-palette`，默认 `default`；其它嵌入的 diff 不传 `palette` 时保持红绿。Files 与审查树文件名单行省略，行盒用足够的 leading 和内边距留住 `g` / `y` / `p`，`title` 仍是完整文件名。

窗口画布支持全应用皮肤切换（`classic` 经典实体、`glass` 液态玻璃 Liquid Glass、`ink` 手绘墨线、`sketch` 素描铅笔纸）。接口只有 `html[data-skin]`；每种皮肤一份 CSS：`packages/ui/styles/skins/classic.css`、`glass.css`、`ink.css`、`sketch.css`，由 `globals.css` `@import`。`ink` 跟昼/夜开关同一套模具：天蓝底、2.5px 墨边、错位投影、`::after` 抖动描边；字/图标走墨色 `#1a1a1a`。`sketch` 是另一套：素描纸 + 淡排线分层，**不要黑框、不要错位硬影**，不改 ink。`glass` 是网页近似（不是 Apple 官方材料）：浅色画布透明、冷石板深色字；暗色覆盖浅字。画布在 `skins/glass-canvas.css`，由 `globals.css` 紧跟 `glass.css` 引入（不要写进 `glass.css` 的嵌套 `@import`，Tailwind 会丢掉）。三张铬外壳（`aside.rounded-3xl` / `main` / 审查栏 `[data-frost=shell]`）填充 26% + `blur(40px) saturate(200%)`，投影走 `--shadow-card` / `--shadow-sidebar` 再叠弯液面。内层卡片浅槽 16%、**不再二次 blur**；嵌套 8%。Composer `[data-frost=chip]` 与外壳同填充、关掉 blur。`#skin-liquid-glass` 只打在 1px 棱镜描边。指针写 `--glass-light-x` / `--glass-light-y`（百分比圆心）和 `--glass-light-angle`（只给描边），禁止 deg×px。外观迷你窗走 `[data-preview-skin=glass]`，禁止组件内 `bg-cyan-400` / `bg-white`。主工作区三张卡片、12px 窗内边距、间隙 `gap-3`。三卡片采用双层物理光学投影系统（`shadow-card` / `shadow-sidebar`），浅色具备细腻触地影与环境漫射扩散，暗色具备 1px 倒角微高光。全应用只有这一套铬（`AppShell`），禁止再弹出「返回应用」第二套侧栏：

## 已知坑

- [open] `no-inline-styles` / `no-unknown-classes` / `require-static-classes` 仍未打开（玻璃皮肤指针、mascot、动态 className 会刷屏）。规则组的整体状态以 [`architecture`](./architecture.md) 的 Lint 段为准，不要在这里再维护一份。
