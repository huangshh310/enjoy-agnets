# spec/i18n

> 界面中英双语。默认中文。最后更新：2026-10-10（本轮写过 / 已停止）
> I1 换模短句见 `chat.modelSwitch.*`，由 `model-switch-invariants` 守门。P2 显示名：`chat.renameEngine` / `chat.engineRealName` / `settings.agentTools.engineDisplayName*`。CU-P1-A：`chat.desktopAllowAlways*` + `settings.builtinTools.alwaysAllow*`（撤销不得写成撕掉/移除/删除/Forget）。CU-P1-P：`chat.desktopSensitiveWarn`（不得写成「已拦截」）/ `intentDesktopShort`（`@{app}`，禁止写死应用名）。CU-P1-36：`settings.builtinTools.advancedCoords*`（正文与 `advancedCoordsTip` 都禁止「逃逸舱 / elementId / 不吃 / snapshot → act」）+ `chat.desktopActFailed*` / `desktopCoordsDisabled*`（禁止「裸坐标」；`errorText` 若是 `bare_coords_disabled` 须走同一套人话）。CU-P0-C overlay：`chat.overlayControlling` / `overlayStop` / `overlayEscHint` / `overlayFallbackApp` / `surfaceDesktopExecuteOnly`；独立 overlay 窗由 main 按 `preferences.language` 灌同一句，不走 React `t()`。CU-P1-B：`chat.mentionKindDesktop` / `desktopChip` 写「桌面」/ Desktop（不要「电脑」）；诚实句 `desktopBiasExploreHonesty` / `surfaceDesktopInterceptTitle` =「桌面控制需切换到执行」/ “Desktop control needs Execute”。

## 当前真相

渲染进程用自研点分路径词表，不引入 i18next。`I18nProvider` 包在 `QueryClientProvider` 内，读 `preferences.language`（`zh` | `en` | `auto`），解析为 `AppLocale` `zh` | `en`。

- 新装默认：`preferences.language = "zh"`。
- `auto`：`navigator.language` 以 `zh` / `en` 开头则跟随，否则中文。
- 设置未返回前、无法识别时：中文。
- `document.documentElement.lang` 为 `zh-CN` 或 `en`。
- `packages/ui` 默认文案走 `setUiLocale` + `uiT(zh, en)`，与界面语言同步。
- 标识符、日志、IPC、模型 ID、路径不翻译。聊天正文与模型输出不翻译。
- 默认面走人话：工作区=当前打开的文件夹，项目=侧栏里的那一项，创建时选的叫文件夹（不再写「源文件夹」）。自动化页 jojo 锁用「项目」（`workspaceHint` / `onSaveHint`）。会话门 `needs_review` 一律「待验收」/ Needs acceptance；差异栏仍说「审查」。无 path 的写类待验收占位句钉死 `chat.sessionReviewCommandPlaceholder`（「这一轮运行了命令，可能改了文件，请到「审查」里核对。」/ “This turn ran commands and may have changed files. Check Review to confirm.”）。有 path 走 `chat.stackedFilesChangedNamed`；git 仓求交为空、回落本轮 path 走 `chat.sessionReviewWroteThisTurn` / `WroteThisTurnMany`（「本轮写过」）；写盘后停/出错走 `chat.sessionReviewStopped`；等审批走 `chat.sessionReviewWaiting`；用户停走 `chat.runStopped` / `chat.toolStopped`（「已停止」）。Dock 默认句是「在「备忘录」里点击「今日」」+「等你决定，画面已定格在提问那一刻」。HMAC / bundle id / 裸动作只在开发者文案档。`@` 菜单桌面组说明钉死「这台电脑上能操控的应用」。线程工具名 `desktop_*` 默认「操作桌面」/「在「备忘录」里点击」。Composer 审批等待钉死「等待应用…」。侧栏/面包屑占位题走 `displaySessionTitle`，中文显示「新对话」，不把库里的 `New agent` 摊出来。中文词条含汉字时禁止半角 `?` / `!`（「放弃未保存的修改？」/「删除这条自动化？」走全角 `？`），`user-copy-invariants` 守门。盾牌悬停三句 `chat.approvalChipHintReads` / `Edits` / `All` 是白话（「全部：助手可直接改文件、运行命令，不再逐条问你」），禁止工具名；由 `approval-chip-hint.test.ts` 与 `user-copy-invariants` 守门。

切换设置里的语言会 `invalidateQueries(["settings"])`，整树重渲染。侧栏底栏主题开关旁有 **中 / EN** 分段，写入 `zh` | `en`（不经 `auto`）。

## 不变量

- 词表中文是结构源；英文必须同键。`flattenMessageKeys(zh)` 与 `en` 必须相等。
- 缺键时 `t()` 返回路径本身，禁止空白。
- 渲染进程不读 OS 主题；语言的 `auto` 只跟 `navigator.language`。

## 已知坑

- 已有数据库里若仍是 `language: "auto"`，按机器语言解析，不是强行中文。要中文请在设置里选中文。
- 模块级常量数组必须改成 `getX(t)`，否则切语言不会更新。（组件内每次渲染用 `t()` 重算 label 亦可，如 `blobatar-picker` 的选项映射。）
- AUTO-P2 C 端禁止摊 `skipped` / `system_sleep` / `catch_up_approval_timeout` / `interrupted_by_restart` / `powerMonitor`。人话只出 `studio.automations.skipReason*` / `catchUpTimeout*` / `catchUpInterrupted*` / `catchUpWhen*` / `catchUpWhenNeverRan` / `missedGroupSame` / `missedGroupMixed` / `missedExpandAction` 与 `chat.automationSource*`，映射集中在 `missed-copy.ts`。英文 `catchUpToggleDefault` 必须含 `Once on,`。未跑补跑钉死「计划 X · 未运行」/ “Planned X · didn't run”，禁止「实际」或带时间的「取消」（`recordedAt` 是开跑时刻）。补跑通知整句由共享 `formatCatchUpApprovalNotice({ automationName, isCatchUp })` 产出，钉死「Enjoy 的自动化「{name}」在补跑，需要你回 Enjoy 审批」；只吃现有 `automationSource` 字段。设置能力句 `settings.setupGuide.capAutoD` 钉死「默认不补跑，可在单条自动化里开启补跑最近一次」。
- 未执行文案跟库里的 reason / `resumeCode` + `decision` 走，渲染层不得自行推断。用户拒绝出 `chat.toolDenied`（「已拒绝，本次未执行」/ “Declined, not run this time”）；`stale_observation` 且 decision 不是 deny 出 `chat.toolStaleObservation`（「画面已经变了，这次没有执行，请重新确认」/ “The screen has changed…”），中性点、不写已拒绝、不当出错；参数不一致出 `chat.toolArgsMismatch`；其余 fail closed 保持原句。工具行用户拒绝仍中性「已拒绝」，不画绿勾、不计入「已运行 N 个工具」、不出红条与「重新生成」。hydrate 按库里的 `output-error`+拒绝码映射未执行，不改写 state。库约束走 `INTERNAL_STORE_ERROR` + `chat.errorGenericHint`，禁止 UNIQUE / SQLite 原文进横幅。
- `t()` 的 vars 类型是 `string | number`。可选数字字段（如 `CuratedSkillSource.skillCount`）传入前必须兜底（`?? ""`），且兜底要保真原 JSX 渲染（undefined 渲染为空，不能改成 0）。
- IPC / main 英文 throw（如 `Refusing to spawn`）必须在 renderer `setError` 前映射成人话，禁止把 Basename / stdio 行话摊给用户。
- 默认词表禁止裸工具名（`desktop_*` / `write_file` 等）、`com.x.y` bundle id、`§` 章节号。HMAC / 裸动作 / bundle 模板只进开发者文案档（`localStorage enjoy-agents-dev-copy=1`），由 `user-copy-invariants` 守门。守门同时钉死 Dock / `@` 菜单 / 线程工具名 / 自动化抽屉 / 说明页的 jojo 原句。含汉字的中文词条禁止半角 `?` / `!`，确认句用全角 `？` / `！`。
- 词表禁止残留 C 端协议微标键：`chat.usage.localToolLoop` / `acpSubscribe` / `sandboxHarness` / `chat.modeAgentBadge`。导轨/胶囊由 `picker-copy-invariants` 守门。
- C 端模式面禁止 `ask|plan|agent` 原文与 ACP / ToolLoop：Composer 分段、设置默认项、拦截条、@ 发现只用「探索 / 执行」。由 `surface-copy-invariants` 守门。内部枚举与 host-mode 围栏可以留 `plan`。
- Recap / Goal 词表：只能写「下一轮发给助手」，禁止「已经注入 / 静默进模型」。失败用 `recapFailed` / `goalSaveFailed`。芯片可见文案一律 `t("chat.generateRecap")`（中文「阶段总结」），禁止已有 recap 时硬编码 `Recap`。
- `GitCommitCard` 标题与审查入口走 `gitCommitCardTitle` / `gitCommitReviewDiff`，禁止中英混写硬编码。
- 会话工作流词表：`statusTodo` / `statusInProgress` / `statusNeedsReview`（待验收 / Needs acceptance） / `statusDone` / `flagSession`（加星标 / Star）与 Inbox `navRunning` / `navWaiting` / `navFailed` / `navComplete` 中英同键。差异栏 `emptyChanges` 仍可写「待审查」。Composer / Environment 用量铬面只写 `formatTokens` 数字，单位 `tok` 留在词表与 tooltip，不要再拼「6 tok」。
- 审批发现性词表（`settings.approvalDiscover.*`）必须是 C 端短句：审批策略 / 每次写盘与命令都需确认 / 本会话已放行部分操作 / 自动批准已开启。禁止 `allow-reads` / `allow_session` / YOLO / HMAC / 权限协议。由 `approval-discover-invariants` 守门。
- 进阶沙箱 / 本机 CLI 顶条 / 供应商 Explore 的用户可见字符串禁止「Vercel」作字段标题；由 `sandbox-debrand-invariants` 守门。注释与 IPC 字段名可以留实现痕迹。
- 仅官方登录失败禁止写「请确认已安装 Oh My Pi」。发送闸 / 密表共用 `loginFailPrefix` + 短原因；`sendGateCopy` 与预览三块文案对齐。
- Registry / Pi / Hermes C 端摘要禁止 ACP / RPC / spawn / stdio。未找到卡用「还没装好这个助手」。由 `cli-b-invariants` 守门。
- 抽屉信任卡 C 端用「体检」「本月用量」，禁止 doctor / ACP handshake / 公开额度 API。由 `drawer-trust-invariants` 守门。
- CLI 过旧 C 端只用「需更新 / 版本过旧 / 请先更新本机助手」。禁止 ACP / stdio / handshake / 立即升级。由 `cli-outdated-invariants` 守门。
- 完成条预览只用「在浏览器打开 / 暂无可预览页面 / 已在浏览器打开」。禁止 Preview / Live / 内嵌预览 / webview。由 `preview-open-invariants` 守门。
- 扩展发现壳 C 端禁止 Registry / 本机 CLI / ACP / stdio / Marketplace / Store。脚注必须写明 Enjoy `#/mcp` · `#/skills` 为真源。I2 精选只用「添加到 MCP / 添加到技能」「已写入 Enjoy · 下一轮可注入」「精选暂时加载不了」，禁止「已同步到助手」。由 `extensions-invariants` + `curated-invariants` 守门。
- I1 换模 C 端只用「已切换 / 已切换到 {model} / 同一助手，不换引擎 / 此引擎不支持中途换模型 / 还没登录… / 还没有可换的模型」。禁止「已切换引擎」「已交接」「会话已重开」「换模会重开会话」「本机助手会话会重开」当成功主句。由 `model-switch-invariants` 守门。
- 设置「本会话任意桌面」无焦点会话时只用「请先打开对话」/ “Open a chat first”（`anyDesktopNeedSession`）。由 `desktop-any-desktop-invariants` 守门。
