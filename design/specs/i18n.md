# spec/i18n

> 界面中英双语。默认中文。最后更新：2026-09-10

## 当前真相

渲染进程用自研点分路径词表，不引入 i18next。`I18nProvider` 包在 `QueryClientProvider` 内，读 `preferences.language`（`zh` | `en` | `auto`），解析为 `AppLocale` `zh` | `en`。

- 新装默认：`preferences.language = "zh"`。
- `auto`：`navigator.language` 以 `zh` / `en` 开头则跟随，否则中文。
- 设置未返回前、无法识别时：中文。
- `document.documentElement.lang` 为 `zh-CN` 或 `en`。
- `packages/ui` 默认文案走 `setUiLocale` + `uiT(zh, en)`，与界面语言同步。
- 标识符、日志、IPC、模型 ID、路径不翻译。聊天正文与模型输出不翻译。

切换设置里的语言会 `invalidateQueries(["settings"])`，整树重渲染。侧栏底栏主题开关旁有 **中 / EN** 分段，写入 `zh` | `en`（不经 `auto`）。

## 不变量

- 词表中文是结构源；英文必须同键。`flattenMessageKeys(zh)` 与 `en` 必须相等。
- 缺键时 `t()` 返回路径本身，禁止空白。
- 渲染进程不读 OS 主题；语言的 `auto` 只跟 `navigator.language`。

## 代码入口

- 运行时：`apps/desktop/src/renderer/src/i18n/`
- 词表：`i18n/catalogs/{zh,en}/`（Attention 短标在 `attention.ts`）
- UI 包：`packages/ui/i18n/ui-locale.ts`
- 默认值：`apps/desktop/src/main/services/preferences.ts`、`packages/ipc-contract` `language.default("zh")`
- 设置项：`#/settings/general` Language；侧栏：`sidebar-locale-toggle.tsx`

## 已知坑

- 已有数据库里若仍是 `language: "auto"`，按机器语言解析，不是强行中文。要中文请在设置里选中文。
- 模块级常量数组必须改成 `getX(t)`，否则切语言不会更新。
- IPC / main 英文 throw（如 `Refusing to spawn`）必须在 renderer `setError` 前映射成人话，禁止把 Basename / stdio 行话摊给用户。
- 词表禁止残留 C 端协议微标键：`chat.usage.localToolLoop` / `acpSubscribe` / `sandboxHarness` / `chat.modeAgentBadge`。导轨/胶囊由 `picker-copy-invariants` 守门。
- 进阶沙箱 / 本机 CLI 顶条 / 供应商 Explore 的用户可见字符串禁止「Vercel」作字段标题；由 `sandbox-debrand-invariants` 守门。注释与 IPC 字段名可以留实现痕迹。
