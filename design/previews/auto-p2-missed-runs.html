jojo 正式验收 · M1–M6

  1. M1 睡过计划点 → 唤醒后「已跳过 · 电脑睡眠 · 时间」；补跑关时不运行
  2. M2 应用关闭期间错过 →「应用未运行」；上一次仍在跑 →「上次仍在运行」
  3. M3 补跑开：只补最近一个，较早点只记跳过；运行记录标「补跑」
  4. M4 多次唤醒/启动，同一点只补一次、只一条记录
  5. M5 补跑要审批时停 Dock 并通知；任意桌面放行对补跑无效
  6. M6 跳过记录仅本机；回看 ≤ 7 天

给 kai / mike 的交接

kai · 检测 / 幂等 / 存储 / 授权

  • 启动 + powerMonitor resume 算错过点；回看 7 天
  • 幂等键 automationId + scheduledAt（参照现网 commandId 防双开，不是每轮新随机）
  • 本机 skipped store；原因三选一：电脑睡眠 / 应用未运行 / 上次仍在运行
  • 补跑走现审批链；不继承 desktop_act:* 任意桌面；按应用放行与始终允许簿照常

mike · 行 / 抽屉 / Dock / 通知

  • 行小标 + 次行「已跳过 · 原因 · 时间」；连续合并「错过 N 次」
  • 抽屉开关「错过后补跑最近一次」默认关；运行记录可折叠组
  • 补跑标 mute；结果用已完成 / 出错 / 已停止
  • Dock 来源句「来自自动化「…」的补跑」；通知无允许钮
