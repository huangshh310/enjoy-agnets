远程工作区 · SSH 开发机

远程 = 工作区在哪台机器，不是第三种引擎。导轨无「远程引擎」。私钥不进 renderer。

锁

  • 开项目：本机文件夹 | 远程 SSH…
  • SSH 抽屉：host / user / port / 认证（agent | 本机 key 路径）/ 远端路径；无私钥内容
  • 顶条：连接中 / 已连接 / 失败 / 断开；未接通 Composer 禁发
  • 脚注「远程 · user@host:path」；文案「远程 ≠ 引擎」
  • runtimeId 不加 ssh；仅官方 CLI 不因远程出现假 vault
