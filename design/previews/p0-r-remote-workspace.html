远程 = SSH 工作区位置 · 不是导轨上的新引擎

设计已锁，应用未接线。本机壳 + 远端 cwd。默认 local。沙箱仍在设置。禁止云多租户 / worktree / 假 BYOK / 粘贴私钥。

锁

  • 模型：local | ssh；默认本机
  • 抽屉：主机 / 用户 / 端口 / 认证 / 远端路径
  • 顶条：连接中 · 已连接 · 失败 · 断开
  • Composer：脚注 远程 · host:path
  • 导轨：不增「远程引擎」

远程 ≠ 引擎。会话本机，代码远端，不默认同步文件夹。

验收

  1. 工作区切换只有「本机文件夹 / 远程 SSH…」；默认本机；远程不是新引擎。
  2. 380 抽屉：主机 / 用户 / 端口 / 认证（本机 SSH Agent 或密钥路径）/ 远端路径 + 连接；短人话；禁粘私钥。
  3. 顶条四态：连接中不可发送 / 已连接「远程 · user@host · path」/ 失败人话+重试 / 断开只读回顾且禁写 + Agent。
  4. Composer 探索 | 执行不变；脚注「远程 · host:path」；断线发送闸「远程已断开，先重新连接才能发送」。
  5. 导轨不增「远程引擎」；沙箱留设置；无假 BYOK / 云多租户 / worktree。

非目标

云多租户 · 沙箱上轨 · 远程引擎 · worktree · 假 BYOK · 默认同步文件夹 · 私钥进对话
