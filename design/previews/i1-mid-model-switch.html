同引擎中途换模型 · 同一助手，不换引擎

Jojo 锁。同一会话、同一引擎，Composer 底栏芯片换模型；角标「已切换」。不是 M3 handoff，不开新会话。设计已锁，不宣称应用 1:1。

锁

  • 芯片 → 只打开当前引擎已宣传 / 已绑定模型表 → 选中：芯片更新 +「已切换到 {model}」
  • 下一轮才生效；历史气泡保留旧模型标；session id 不变
  • 不支持：禁用 +「此引擎不支持中途换模型」。失败：未登录 / 不支持 / 列表空 + 重试。禁止空成功
  • ≠ 换引擎 / 新会话 / 假交接卡 /「已切换引擎」/ 模型菜单夹引擎 / 清上下文 / 自动 commit-push / worktree

验收

  1. 换模后没有新的 session id。
  2. 没有「已切换引擎」文案。
  3. 不支持 = 禁用 + 一行原因，不是空成功。
  4. 弹层只有当前引擎模型，不含第二引擎导轨、不含协议微标。
  5. 成功写「已切换到 {model}」/「已切换」，不写「已交接」、不画交接卡。
  6. 历史保留旧模型标；新模型下一轮才生效。
