本机 Automations · 定时或手动开一轮

Jojo 锁。诚实 local-only：到点或手动开一轮会话 / 工作单。不做云调度、不做团队看板派活。加深现有 #/settings/automations（manual / on_save 已有）；I4 是 cron + 诚实本机，不是第二套产品。设计已锁，不宣称应用 1:1。

锁

  • 路由仍是 #/settings/automations。列表是紧凑 C 端行，不是营销卡。
  • 行：名称 · 触发（手动 / cron 简写）· 上次运行或「尚未运行」· 开/停。可选胶囊：空闲 / 运行中 / 失败。
  • 编辑走右侧抽屉约 380px：名称、触发、cron+时区、引擎、可选模型、探索\|执行、提示词。主钮保存；手动才出次钮「立即运行」。
  • 本刀 P0 触发 = 手动 · cron。「保存后」/ webhook 灰掉或脚注「本刀不做」。
  • 页脚固定：「仅在本机运行，关闭应用则暂停」。失败进 Inbox「失败」，不挤待验收（F1）。
  • 开流仍走现 Composer + P0-S 注入。不新 runtime、不新铃、不新看板。

  3. 失败进 Inbox「失败」，不挤待验收（F1）。
  4. 开流仍走 P0-S 注入；无新插件市场。
