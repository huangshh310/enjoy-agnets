Composer 提及 @桌面 / @应用 · 偏置宿主，不跳过闸

短锁 cu-p1-b-composer-mention.md · 对标 Codex @Computer/@App · 基线 tip 281520e（overlay 已合） · I3 Registry more-agents 仍停 · 不宣称应用已 1:1。 产品锁写 @桌面，不要沿用旧预览 @电脑。

一句话 · 提及偏置 desktop_*；非插件店，不跳过审批

做

  1. @桌面：Execute 下偏置桌面工具总入口（选用 desktop_*）
  2. @应用名：点名本机可枚举应用（与 desktop_list_apps 同源或等价），展示名 + 稳 appKey；提及后偏置该应用
  3. 全链路仍走闸：Approval Dock / 会话表 / Always-allow / 二次确认 / overlay；提及 ≠ 放行
  4. Explore：提及时不注册 desktop_*；提示「桌面控制需切换到执行」；勿静默失败、勿装已连接
  5. 无稳 appKey：可进候选，不露「始终允许」路径

不做

  • Registry / 插件店 / 虚构未装应用
  • 提及 = 跳过审批或裸 desktop_act:* 永允
  • 第二套远程壳
  • Explore 下点亮 overlay 或注册桌面工具

验收 B1–B4

  1. B1 Execute + @桌面 → 偏 desktop_*；首次 act 仍进 Dock（除非会话/簿已放行）
  2. B2 Execute + @计算器（名单内）→ 偏该 appKey；点别的 app 仍按 §3.2b 再批
  3. B3 Explore + @桌面 → 无 desktop_* + 可见「需切换到执行」人话
  4. B4 候选无假应用；无稳 key 不走始终允许
