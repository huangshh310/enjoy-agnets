jojo 正式验收 · O1–O4

  1. O1 act 亮/熄：desktop_act 进行中蓝边亮；act 结束或停止后熄
  2. O2 右栏一致：右栏 Desktop 与当前观察窗 / 步骤卡缩略图同一 appKey + 同一观察
  3. O3 停后不再 click：点「停止」后 overlay 熄灭，后续 click / type 不再当作在控态
  4. O4 Explore 无 overlay：探索模式无蓝边、无「正在操控」条、无 desktop_act 芯片点亮

做

冷静蓝边呼吸（不是霓虹 HUD）· 顶栏「正在操控 · {app}」+「停止」· 点明 Esc 可打断 · 右栏「正在看的窗口」与步骤卡同一 app / 同一 obs

不做

第二套全屏遥控器 / 漂浮远程工具条 · Composer 脚注墙 · Explore 点亮 overlay 或注册 desktop_act · 无观察仍画「在控」或假绿「已连接」

给 mike / kai 的交接

mike · 铬与右栏

  • 沿用已有 overlay 窗，换成冷静蓝边 + 中文「正在操控 · {app}」+「停止」；禁霓虹绿点 / 英文 Computer Use HUD / 点击波纹当主语言
  • 右栏 desktop-view 与步骤卡缩略图同一 appKey + 同一 observationId
  • 无观察：文案「还没有桌面观察」，不占「在控」铬，不画已连接绿
  • 探索态：不画 overlay，desktop_act 芯片划掉；诚实条沿用「探索模式没有桌面操控工具」
  • 勿第二套遥控器、勿脚注墙、勿底栏 Tab、勿 Registry

kai · 生命周期

  • overlay 只在 desktop_act 进行中点亮；成功结束 / 失败 / 「停止」/ Esc 立即熄
  • 停后账本不得把后续 click / type 当在控；需新观察 + 新审批（硬每次问仍每次问）
  • 「停止」是打断入口，不是第二套远程工具条；Esc 与按钮同一条停路径
  • Explore 不注册写工具 ⇒ 主进程根本不该 ensure overlay
  • 本刀只锁视觉；产品 TS 另刀。I3 仍停

C 端门（luna）：act 才亮边 · 右栏与观察同身份 · 停后熄且不再 click · Explore 零 overlay。
