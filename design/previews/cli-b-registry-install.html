验收

  • 检测中 ≠ 就绪（不放行发送，不画绿灯）
  • 未找到随配方：一键 或 仅复制；无白名单安装器不假一键
  • 失败一行「未装上：…」+ 重试；禁假进度条
  • 密表三列同构；未找到 / 自定义无动力源画 —；禁假 BYOK / 假 vault
  • Registry 空卡写「还没装好这个助手」
