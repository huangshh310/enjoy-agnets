Registry · 仅复制

Oh My Pi / Hermes

还没装好这个助手

没有白名单安装器。复制是主行动，不要画假一键。curl | bash 只展示不执行。

curl -fsSL https://omp.sh/install | sh

文案表

面写不写
Registry 空还没装好这个助手已连接 / 即将就绪
失败行未装上：{短原因}npm 堆栈、假进度
已装未就绪检测中 / 待登录绿灯「已安装」当就绪
动力源 · 官方官方登录 · 检测中 / 未登录假 vault 下拉
动力源 · 未找到 / 自定义空—官方登录 · 检测中
仅复制复制命令（主钮）假一键安装
自定义安装只能选支持的助手程序，不能指定电脑上的任意软件basename / stdio 行话
白名单拒绝无法使用「…」英文 throw 上屏

验收

  • 密表永远三列同构；未找到 / 自定义无动力源画 —，不造假 vault
  • 未找到随配方：一键 或 仅复制；失败必有「未装上：…」+ 重试
  • 已装未就绪：检测中 ≠ 绿灯；动力源「官方登录 · 检测中 / 未登录」
  • 无白名单安装器时复制是主行动，禁止假一键、假进度条
  • Registry 空卡诚实写「还没装好这个助手」；自定义仍白名单人话
  • 本页是视觉真源，不宣称应用已 1:1
