给 kai / mike 的交接

kai · 快照 / 匹配 / 计算 / 档案 / IPC

  • models.dev 离线快照进 packages/providers，带版本和日期；五项每百万 USD
  • 档案模型可选手填单价，覆盖快照；自定义端点默认未知
  • provider + modelId 精确命中；别名只认快照写明的
  • 分项计价；有 token 无单价 → 整次未知。主路径不联网
  • estimatedCost 要能表示未知（不要再写死 0）；缓存/推理分项按需补进 usage / metric

mike · 用量行 / meter / trace / 设置栏

  • rail 要真的传入本轮 token；花费跟在「本轮 {n} tokens」旁，估算是 mute 小字
  • meter 可见仍是 tok；悬停加花费。有未知：已知部分 · N 次价格未知
  • trace 标头画出花费；未知「—」，不再恒 0
  • 模型行展开「单价（可选）」五格；占位「快照 $x」或「未知」；本地只留一句不计费
