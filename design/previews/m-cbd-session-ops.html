锁

  • M-C 安静 Inbox：筛选只要 拍板 | 待验收 | 失败。默认藏工具噪音。徽标=拍板数（示例 1），不计运行中 / 完成 / 读文件刷屏。

  • M-D 运行账本：右侧只读时间线（工具 / 命令 / 错误 / 用量）。点行 → P0-G 式 sheet「本轮来源」。不上新模块页，不写 Observability 大盘。

验收

  1. 左栏安静 Inbox：筛选只有拍板 / 待验收 / 失败；拍板筛下列表只有拍板条；默认不画工具噪音；徽标 = 1 且只计拍板。
  2. 中栏待验收：顶栏执行中 | 待验收 | 完成；同一屏 diff +「在浏览器打开」+「本轮来源」+ 打回 / 通过；不自动 push / commit。
  3. 右栏账本只读（工具 / 命令 / 错误 / 用量）；点行打开 P0-G 式「本轮来源」sheet。
  4. 联动：Inbox「待验收」打开中栏闸门；账本行打开「本轮来源」。无看板、无第二 Inbox、无 worktree、无协议微标。
