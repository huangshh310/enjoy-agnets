验收提醒（真机 7 屏 · 本 HTML 不算过门）

  1. 弹层只有本引擎模型；无夹引擎。
  2. 成功写「已切换」/「已切换到 {model}」；无「已交接」「已切换引擎」。
  3. session id 不变；历史旧标保留。
  4. 不支持 / 未登录 / 空表诚实；禁空成功。
  5. 写入中 busy + 防连点；失败回旧名。
  6. 跑着可切 +「下一轮才用新模型」；本轮气泡仍旧标；Dock 待批仍可换模。
  7. 不挡权限芯片 / 发送·停止 / 审批坞；无 Composer 上方常驻换模微条。
