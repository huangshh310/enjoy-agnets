助手显示名 · 本机标签，空则引擎名

Jojo 锁。芯片与侧栏优先画显示名；trim 后空回退引擎名。品牌标仍认引擎。换名 ≠ 换引擎。设计已锁，不宣称应用 1:1。

锁

  • 瘦身单一引擎·模型芯片左段：显示名（有）或引擎名（空）。右段仍是模型。图标仍认引擎品牌，不随自定义字串变
  • 侧栏会话行 / 引擎轨：显示名优先；空则 Grok / Claude / Enjoy Local
  • 设置「显示名」输入；hint 空则显示引擎名；保存立刻反映芯片与侧栏
  • 禁止把「未命名助手」当正式身份。显示名只是本机标签，不改 runtimeId / 登录 / 用量账户
  • ≠ 小队 / 多席位 / 看板 / 云端花名册 / 把换名画成换引擎

验收

  1. 芯片左段：有显示名画显示名，空则引擎名；右段模型不变；图标仍认引擎。
  2. 侧栏会话行 / 引擎轨同一套回退，不出现常驻「未命名助手」。
  3. 设置有「显示名」+ hint「空则显示引擎名」；保存立刻改芯片与侧栏。
  4. runtimeId / 登录 / 用量账户不随显示名变。
  5. 无小队列表、无看板列、无云端花名册同步。
