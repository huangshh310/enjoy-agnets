验收

  1. 完成 / Review 条有次级「在浏览器打开」；主钮仍是「审查」。
  2. 选中工作区 *.html 或本会话有本地预览 URL 才可点；否则禁用，悬停「暂无可预览页面」。
  3. 点击走 main shell.openExternal，toast「已在浏览器打开」；不嵌 Chromium。
  4. 探索态只读可开，不自动起 dev server。
