# P0 · Composer 输入区瘦身 — 产品短锁（紧急）

> 2026-09-20 · jojo  
> 触发：真机「设计臃肿太复杂」——模式面过宽、引擎/模型双份、P0-S 脚注墙、目标/阶段挤占  
> 真源预览：`design/previews/p0-composer-slim.html`  
> 入库：`design/references/p0-composer-slim.md`  
> **插队**：高于 I2 接线；I2 预览可并行，实现让路本刀  
> 不废：C1 探索|执行、I1 换模、P0-S SoT（只改**呈现密度**）

---

## 一句话

Composer **一屏只留主行动**：输入 + 精简铬条。次要信息进抽屉 / 悬停 / 一行芯片；**禁止**脚注墙、双引擎条、目标阶段常驻占高。

---

## 常驻（默认可见，≤ 两行铬 + 输入 + 底栏）

| 位 | 内容 | 规则 |
|----|------|------|
| 铬条 L | **探索 \| 执行** | 保留 C1；控件紧凑分段，**不**并排「设置目标」「阶段总结」 |
| 铬条 R | **单一**引擎·模型芯片 | **只一份**（图标+短名+模型）；点开 = 引擎 Picker / I1 模型；用量%进芯片悬停或 Popover，**禁止**第二条 grok 行 |
| 主区 | 输入框 | 主焦点 |
| 底栏 | 发送 + 必要 token/附件 | 「全部」若非主路径 → 收进 `…` 菜单 |

思考档：有 capability 时进模型芯片旁 **小档位** 或模型菜单内；不单独占一整行宽条。

---

## 收起（默认不占垂直空间）

| 项 | 去哪 |
|----|------|
| 「设置目标」「阶段总结」 | **会话顶 / 溢出菜单 `…`**；禁止贴在探索\|执行旁常驻 |
| P0-S 长脚注「真源在 Enjoy；助手只消费。原生插件…」 | **设置 → 扩展** 或注入 Popover 内小字；Composer **不**常驻脚注墙 |
| 「管理」双深链 | 收进注入芯片的 Popover 单一「管理扩展」 |
| 双份引擎/模型条 + 重复 74% | **删除重复**；% 只挂一份芯片 |
| 已注入明细展开名单 | 默认折叠；点芯片展开 sheet/popover |

---

## P0-S 微条显隐（锁）

| 条件 | UI |
|------|-----|
| 启用 MCP+Skills **均为 0** | **不画**任何注入条（沿旧锁） |
| 有启用 | **一行芯片**：`扩展 · MCP n · Skills m`（或更短 `MCP n · Skills m`） |
| 点芯片 | Popover：已启用摘要 / 已注入本轮 / 不支持说明 / 单一「管理扩展」深链 |
| 不支持引擎 | 芯片变淡或叹号；点开见诚实卡——**仍一行**，不铺两句警告占高 |
| 禁止 | Composer 内多行脚注墙；空成功「已同步到助手」 |

---

## 目标密度（验收直觉）

红框输入区垂直：铬一条 + 输入 +（可选一行扩展芯片）+ 底栏 ≈ **清爽可扫**。  
主行动顺序一眼清楚：选模式 → 输入 → 发送；换引擎/模/扩展为次级点击。
