## 做

### M-D 运行账本

- **只读**时间线；入口仍会话侧栏（或合订预览右栏）
- **分组**（至少一种，可组合）：
  - 按回合 / 时间块，或
  - 按种类：读 · 改 · 命令 · 错 · 用量
- 默认折叠「命令」类：只显示 `bash · npm test · 失败` 一级；输出进展开
- 用量：有真实 token 才一行；无则不画假条
- 点 **文件相关行** → 打开本轮来源 sheet（P0-G）；点纯命令行 → 展开输出或仍可开 sheet 若有关联 path

### P0-G 本轮来源

- 同一张 sheet（不新开「来源中心」页）
- 有文件/技能/MCP 才列出；**空态诚实**，禁空白主区
- 芯片点击仍只开 sheet（P0-G 已有锁可保留）
- 可读：路径可截断 + hover 全路径；技能/MCP 用人名不堆协议微标

## 不做

- 第二套 Inbox / 观测大盘 / 看板  
- 改 M-CBD 状态机（待验收/失败/拍板）— **F1 专管**  
- 账本内批准工具、commit、push、重跑（重跑走会话已有入口）  
- 假进度、假来源占位卡片充数

## 验收

1. 一轮含多次 bash：默认账本 **不**刷满输出；≤ 数条摘要行可扫完。  
2. 无文件改动的轮次：来源 sheet 空态可读，不空白崩。  
3. 有改文件：点账本文件行 → sheet 列出对应源。  
4. 无新增导航项；PermissionDock / 审核闸行为不变。
