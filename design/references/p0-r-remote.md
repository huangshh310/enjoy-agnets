## 远程是什么

**远程 = SSH 工作区位置**，不是导轨上的新引擎。

用户打开的是「哪台机器上的哪个目录」。Enjoy 壳、会话、审批、引擎选择仍在本机。工具循环的 cwd 指向远端路径。

工作区模型：`local | ssh`。默认 `local`（本机文件夹）。

一句话：**本机壳 + 远端 cwd**。

## 远程不是什么

| 不是 | 为什么 |
|---|---|
| 云多租户 | 第一期可以完全没有云。远程不是「把项目上传到 Enjoy 云」 |
| 沙箱上轨 | 进阶沙箱继续呆在设置，不上 Composer / 引擎导轨 |
| 远程引擎 | 不在导轨加「远程引擎」。Claude / Cursor / Enjoy 本地仍是引擎；SSH 只换位置 |
| worktree | 不做 M5 git worktree，也不用 worktree 冒充远程目录 |
| 假 BYOK | 不把私钥、云 Key 贴进对话或渲染进程 |

## Local-first 五态

诚实状态，禁止假绿灯。

| 态 | C 端 | 发送 / 写盘 / Agent |
|---|---|---|
| 本机（默认） | 本机文件夹 | 与今天相同 |
| 连接中 | 连接中… user@host · path | 不可发送。不算已连接 |
| 已连接 | 远程 · user@host · path | 可发送；写盘与 Agent 走远端 cwd |
| 失败 | 没连上：{短人话} + 重试 | 不可发送。禁堆栈原文 |
| 断开 | 已断开 · 只能回顾对话 + 重新连接 | 只读回顾；禁写 + 禁 Agent，直到重新连接 |

Composer 脚注（已连接）：`远程 · host:path`。探索 | 执行分段不变。断线发送闸：`远程已断开，先重新连接才能发送`。

## 数据落点

| 落哪 | 什么 |
|---|---|
| 本机 SQLite / 会话 | 对话、审批、引擎绑定。断线后仍可回顾 |
| 远端路径 | 代码、Git、bash cwd。不默认同步整夹到本机 |
| 本机 SSH 配置 | 主机 / 用户 / 端口 / 认证方式 / 远端路径。不进聊天记录 |

不默认同步文件夹。不要做成「先把远端拷到本机再跑」。

## 密钥边界

- 认证只允许：**本机 SSH Agent**，或本机**密钥路径**（如 `~/.ssh/id_ed25519`）。
- **禁止**把私钥贴进对话、Composer、设置大文本框。
- renderer 不读明文私钥，不把 Key 当聊天附件。
- 密钥不进 Git，不进云多租户。

## 验收

1. 远程 = SSH 工作区位置，不是新引擎。
2. 380 抽屉字段齐全，C 端短人话，禁粘私钥。
3. 顶条四态诚实：连接中不可发送；已连接写 `远程 · user@host · path`；失败人话+重试；断开只读且禁写 + Agent。
4. Composer 探索 | 执行不变；脚注 `远程 · host:path`。
5. 导轨不增「远程引擎」；无沙箱上轨 / 假 BYOK / 云多租户 / worktree。

非目标：云多租户、沙箱上轨、远程引擎、worktree、假 BYOK、默认同步文件夹、私钥进对话。
