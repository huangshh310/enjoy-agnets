> 版本：1.0  
> 日期：2026-09-05  
> 读者：产品、设计、实现知识页的 Agent  
> 范围：`#/knowledge` 及与对话的衔接  
> 现状入口：`apps/desktop/src/renderer/src/components/knowledge/`  
> 领域契约：[`knowledge.md`](./knowledge.md) · 视觉规约：[`../../DESIGN.md`](../../DESIGN.md)

本文只改**展示与交互层级**，不改本地 RAG 不变量（路径 jail、显式加源、无 embedding 时词袋兜底、renderer 不读盘）。

---

## 1. 问题陈述

当前知识页是「四个等宽文件夹卡 + 未索引文件表」。它在回答运维问题（源在不在、要不要重建），没有回答用户问题：

> 这批记忆现在能不能问？问完能不能钉进当前对话？

这与 spec 已写的原则冲突：**检索先行，索引退后。**

同时触犯 `DESIGN.md` 两条禁令：

- `[Generic-SaaS-Card]`：四张同尺寸、居中大图标、底部状态条。
- 证据不优先：页头口号 + 运维卡占满首屏，试检索缩成描边按钮。

工程侧（chunk、hash resume、rebuild、`citeKnowledge`）可以保留。要改的是**这一屏在讲什么故事**。

---

## 2. 产品定位

| 不是 | 是 |
|---|---|
| 磁盘文件管理器 | 本地、可审计的记忆层 |
| 云知识库控制台 | Agent IDE 里的检索舞台 |
| NotebookLM 克隆 | 对着工作区说话的透镜（lens） |
| 索引运维首页 | 问 → 命中 → 钉进对话 |

差异化（Cursor 几乎不给知识页、NotebookLM 不对着代码仓库）：

1. 用户显式选择范围，而不是静默索引全盘。  
2. 命中片段可解释、可预览、可 Pin to chat。  
3. 索引状态诚实：0 个分块就不能叫「已索引」。

---

## 3. 设计原则

1. **检索是首页，索引是抽屉。**  
2. **UI 原子是 snippet（可检索记忆），不是 folder。**  
3. **集合是透镜，不是目录封面。** 开关决定这次问哪些源。  
4. **数字必须可行动。** 「17 文件 · 0 分块」拆成可问块 / 仅扫描 / 失败源。  
5. **错误降级。** `ENOENT` 和绝对路径不准印在主卡面。  
6. **非对称 Bento。** 禁止四张克隆卡。  
7. **只用 BoardUI token 与复合字号。** 禁止野生色值和拆字号。  
8. **和对话闭环。** 没有 Pin / 引用回跳，这页没有存在理由。

## 4. 信息架构

```
#/knowledge
├── 检索舞台（默认落地、占主高度）
│     ├── 查询输入
│     ├── 命中 snippet 流
│     └── 空态：最近被 Agent 引用的片段
├── 记忆层 Bento（次高）
│     ├── 脉冲指标（可问块 / 覆盖 / 上次命中）
│     ├── 当前透镜（集合开关 + 默认范围）
│     └── 健康条（缺失 / 错误，折叠）
└── 索引抽屉（默认收起）
      ├── 来源列表（路径、状态、Resume / Rebuild）
      └── 文件矩阵（可检索性、块数、最近引用）
```

左栏「知识集合」与主区卡片**只保留一处**集合导航。推荐：左栏做范围切换（全部 / 单源），主区不再重复四张卡。

添加 / 导入、重建索引进页头次要操作或抽屉，不和「问」抢主按钮。

## 5. 页面结构（一屏）

### 5.1 顶栏

- 左：`Breadcrumb`「知识」+ 当前工作区短名。  
- 中：无居中 Hero、无「本地零云 RAG」营销徽章。  
- 右：次要「添加来源」；主操作是舞台内搜索，不在顶栏再放「测试检索」。

字号：`text-title-3-semibold` 作页标题，说明用 `text-caption-1-regular` + `text-text-secondary`。

### 5.2 检索舞台

容器：`bg-background-primary-default`，`shadow-card`，24px 圆角。

**输入**

- 单行，占位：「用自然语言问这批记忆，例如：登录态写在哪」  
- 回车即搜（走现有 `knowledge.search`）  
- 右侧可开「仅当前透镜 / 全部已就绪源」

**结果卡（snippet）**

| 元素 | 规则 |
|---|---|
| 左 2px 色条 | 映射集合，不是彩虹装饰 |
| 正文 2–3 行 | `text-body-regular`，命中词用 `text-accent-500` |
| 路径 | `text-caption-2-medium` + `text-text-tertiary` |
| 相关度 | 细环或墨水浓度，禁止大百分比 |
| 主按钮 | 「钉到当前对话」→ 会话上下文芯片（不进输入框） |
| 次按钮 | 预览原文 / 只保留此源 |

无结果：一句「当前透镜里没有足够分块」+ 「去索引」链接。禁止空白表。

未检索：展示最近 `citeKnowledge` 命中（最多 5）。这是 IDE 连接点。

### 5.3 记忆层 Bento

栅格：`col-span-2` + 两个 `col-span-1`，禁止四等分。

**脉冲（span-2）**

- 主数字：可检索块数（`knowledge_chunks` 有向量或词袋可用）  
- 辅：已解析文件 / 仅扫描未入库 / 失败源数  
- 0 块时主文案改为「还不能问」，主按钮「为当前透镜建索引」  
- 禁止把未入库文件算进「已索引」

**当前透镜（span-1）**

- 列表：源名、块数、开关  
- 星标 = 默认检索范围，文案写清，禁止无说明空星  
- 不在工作区的源不出现在透镜里，只进健康条

**健康条（span-1）**

- 一行：「2 个源不在当前工作区」  
- 展开：短路径 +「重新选择」+「从本工作区移除」  
- 禁用对该源的「立即索引」（磁盘不存在时）

### 5.4 索引抽屉

触发：脉冲上的「管理索引」或健康条。

文件表列：

1. 文档与相对路径  
2. 所属透镜  
3. 可检索性：有块 / 仅扫描 / 忽略 / 失败  
4. 块数  
5. 最近引用（无则 —）  
6. 操作：预览、从源排除  

状态文案统一中文（或当前 locale），禁止卡面中文、表内 `Unindexed` 混用。

筛选「全部已索引文件」必须只含有块的文档。仅扫描文件走另一 chip。

## 6. 状态与文案

| 真相 | 用户可见 | 禁止 |
|---|---|---|
| 有 chunk | 已可问 · N 块 | 「已索引 17 文件」在 0 块时出现 |
| 扫到未入库 | 仅扫描 | 算进全部知识完成态 |
| 源路径逃出或不存在 | 不在当前工作区 | 打印 `Error: ENOENT: ...` |
| 索引中 | 正在写入记忆 · 文件数可涨 | 转圈无数字 |
| Pause | 已暂停 | 假进度 |
| embeddings stale | 词袋兜底，回答偏弱 | 假装已向量化 |

添加来源成功：立刻刷新列表；Indexing 中按现有 1.5s 轮询 `knowledge.documents`。

## 7. 视觉与运动

遵守 Mist / 炭黑画布、浮动卡片、`shadow-card`、单一 `accent-500`。

**要做的差异化（结构 + 光，不加新色盘）**

1. **问一句，点亮一层**  
   有命中的透镜：`BorderBeam` 或 accent 细边；无命中降到约 40% 透明度。检索结束 300ms 内完成，禁止长动画挡操作。

2. **覆盖是纹理**  
   透镜表面用极淡点阵表示块密度。0 块 = 空白纸；indexing 时点阵增多。点阵用 `text-tertiary` 级对比，不抢正文。

3. **Snippet 是主视觉**  
   小卡、左色条、路径微标。大文件夹图标退出主舞台。

4. **高光只给活跃透镜**  
   暗色 `Specular Rim` 仅用于正在参与检索的源。

**不做**

- 四色大文件夹墙  
- 居中营销 Hero  
- 装饰性宇宙知识图谱  
- 「零云 RAG」徽章  
- 卡片上喷系统 errno  
- 手写 hex、`h-screen`、原生 `alert`

## 8. 与对话的契约

| 动作 | 行为 |
|---|---|
| Pin to chat | 写入会话上下文芯片；发送时把 snippet 拼进用户消息（已有 spec） |
| Agent 开跑 | `citeKnowledge` 用用户最后一句；结果 `source.added` |
| 点击 citation | 打开同一 snippet 预览，设置 `selectedPath`，不要只切 tab |
| 知识页看到「被用过」 | 该 chunk / 文件在抽屉里有引用标记 |

知识页可以关着；Chat 里应能 `@` 或从芯片跳回本页检索态。

---

## 9. 交互细节

- 默认焦点在检索输入。  
- `View Files` 必须先设 `selectedPath` 再切文件视图。  
- 编辑来源：路径未改也可点 Rebuild；卡住 Indexing 也可点。  
- 预设卡目录不存在：禁用 Index Now，给重选。  
- 弹层 `overflow-x-hidden`，隐蔽原生滚动条。  
- 表格 `w-full` + `overflow-x-auto`。  
- 确认用应用内 `ConfirmDialog`，不用 `window.confirm`。

## 13. 参考（结构，不抄皮肤）

- NotebookLM：源可开关、回答带引用、知识是原料不是文件行。  
- Cursor：索引尽量隐形；Enjoy 必须多出「显式范围 + 试检索 + Pin」。  
- Mem：入口是找回，不是文件夹墙。

Enjoy 的正确位置：**本地透镜 + 可钉记忆 + 对工作区诚实。**
