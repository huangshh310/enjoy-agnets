## 一句话

本机 CLI / Registry 列表加 **「更多助手」** 分组：未验证或即将推出的 ACP 引擎可发现、可标状态；**不**默认 `npx` 临时下载，**不**把 Registry 做成插件市场。

---

## 做

| 面 | 锁 |
|----|-----|
| 入口 | 智能体设置 · 本机 CLI / Registry 页 |
| 分组 | **已就绪** · **更多助手**（comingSoon / 未验证） |
| 行 | 名、一句话、状态芯片（即将推出 / 需安装 / 可试装） |
| 动作 | 已支持安装路径的 → 沿 CLI-B 安装；仅花名册 → 「了解」/文档链，禁假「已连接」 |
| 文案 | 分组说明：「以下助手协议兼容性仍在验证，安装前请看状态」 |

## 不做

- 默认 `npx` 一次性拉取当正式引擎  
- Registry 卖 MCP/Skills（≠ I2）  
- 云市场计费  
- 改瘦身 / Automations / 显示名  

## 验收

1. Registry 页能看到「更多助手」分组与至少 2 个 comingSoon/未验证条目。  
2. 未就绪项不能点成「已就绪」空成功。  
3. 与已就绪 CLI 表不混；无协议微标堆砌。

## Luna 一句话

Registry 下半「更多助手」：状态芯片 + 禁用主按钮或「了解」；上半仍是已就绪密表。
