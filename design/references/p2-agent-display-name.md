# P2 · 命名身份（显示名）— 产品短锁

> 2026-09-20 · jojo  
> 对照：Multica「智能体也是队友」——**只抄显示名**，不抄小队/看板  
> 预览：`design/previews/p2-agent-display-name.html`  
> 入库：`design/references/p2-agent-display-name.md`  
> 队列：#70 I2 后 **下一刀（P2 薄）**

---

## 一句话

给本机引擎/会话一个可选 **显示名**（如「前端搭档」），铬条与会话列表用人话名；**不**做小队、leader 派活、名片社交。

---

## 做

| 面 | 锁 |
|----|-----|
| 作用域 | 优先：**每个 runtime/引擎实例** 可设显示名；会话可继承，允许会话级覆盖（P2 可先只做引擎级） |
| 编辑 | 引擎设置 / Picker 行「重命名」；空则回退品牌名+模型 |
| 展示 | Composer 单芯片、会话侧栏、Inbox 行：显示名优先，悬停仍见引擎真名 |
| 存储 | 本机偏好；不进云身份 |

## 不做

- Multica 小队 / 看板负责人  
- 强制每人设名  
- 头像社交网络  
- 改 SoT / 瘦身 / I2  

## 验收

1. 给 Claude 设「代码审」→ 芯片与列表显示该名。  
2. 清空显示名 → 回退默认引擎名。  
3. 不影响探索|执行、换模、扩展注入。

## Luna 一句话

芯片/列表带显示名 + 设置行重命名；空名回退。勿画小队卡片。

---

## 可选并行（不挡）

若你想更高价值下一刀，可改切 **I4-P1：webhook / 保存后触发**（补全 Automations）。本锁默认走命名身份。
