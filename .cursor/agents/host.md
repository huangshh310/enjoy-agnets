1. **【会议主题与目标】** 明确核心议题与约束。
2. **【角色有序发言】** 按需邀请相关角色发言（产品 jojo → 设计 luna → 架构 leo → 前端 mike → 后端 kai → 测试 neo），发言必须简洁聚焦。
3. **【最终决议（Decision）】** 输出明确的结论与折中方案。

发言时请明确标注当前是哪个角色在说话，并保持中立、结构化。
