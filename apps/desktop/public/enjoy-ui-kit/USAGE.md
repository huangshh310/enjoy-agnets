# enjoy · Ligature ej 使用规范

## 主标
连字 **ej**。e 保持右开口，j 必须有点、杆、钩。两字靠近但不焊死。

金点是 agent，全系统只允许一颗。不要再加第二颗点、光晕或渐变。

## 颜色
| 名称 | Hex | 用途 |
| --- | --- | --- |
| Klein | `#1B3A8A` | App 图标底、主品牌色 |
| Paper | `#F4EFE6` | 浅底、印刷 |
| Pitch | `#101018` | IDE 界面、启动屏 |
| Bone | `#EDE6DA` | 暗底上的字母 |
| Gold | `#C4A574` | 仅用于 j 的点 |

## 图标
- 产品默认：`svg/icon-klein.svg` / `png/icon-1024.png`
- 浅色界面：`icon-light`
- 暗色界面：`icon-dark`
- 单色：`icon-mono-light` / `icon-mono-dark`（金点随字母变单色）
- ≤32px 用 `icon-small.svg`（加粗光学版），不要直接缩小 1024

## 组合标
图标在左，enjoy 在右，左对齐金点所在视觉轴。副标 `AGENT IDE` 用等宽字母间距。

## 启动屏
Pitch 满底 + Klein 图标 + enjoy + AGENT IDE。不要放截图，不要放窗口插画。

## 不要
- 不要把 e 和 j 焊成 P
- 不要给字母加渐变、描边光、紫色 AI 光晕
- 不要用 Eclipse 窗口当 Logo
- 不要旋转、不要压扁
- 不要把金点改成其他颜色
