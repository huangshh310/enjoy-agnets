# Enjoy Agents Browser Bridge — Chrome 扩展

用于将你的日常 Chrome 浏览器与 Enjoy Agents IDE 建立本地安全桥接连接。

## 如何在 Chrome 中加载此扩展

1. 打开 Google Chrome 或基于 Chromium 的浏览器（Edge、Brave、Arc 等）。
2. 在地址栏输入并打开：`chrome://extensions`
3. 打开右上角的 **「开发者模式」 (Developer mode)** 开关。
4. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
5. 选择当前目录：`apps/browser-extension`。
6. 加载完成后，在浏览器扩展栏点击 **Enjoy Agents Bridge** 图标。
7. 从 Enjoy Agents 设置中心（`内置工具` → `Browser Bridge`）复制 **配对码**，粘贴并点击 **连接客户端** 即可！
